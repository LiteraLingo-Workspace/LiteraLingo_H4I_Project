# Frontend Documentation

## How to run

run `npm run install` to run the frontend

## How to create components

### Label

Example:

```
      <Label color={"coolAccentBg"} bg={"faintBlue"}>
        Metaphor
      </Label>
      <Label color={"warmYellow"} bg={"faintYellow"}>
        Simile
      </Label>
```

### Text Input Field

Example:

```
      <TextInputField type="email" placeholder="Enter your email"></TextInputField>
```

## Pull Requests

Developers when submitting Pull Requests should use the template in PRTemplate.md to ensure quality and testing.
